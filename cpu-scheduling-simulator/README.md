# CPU Scheduling Simulator

## Overview
The CPU Scheduling Simulator is a web-based application designed to help users understand and visualize various CPU scheduling algorithms. It allows users to input process details, select scheduling algorithms, and view the results in a user-friendly interface. The simulator supports multiple algorithms, including First-Come, First-Served (FCFS), Shortest Job First (SJF), Round Robin, Priority Scheduling, and Multilevel Queue Scheduling.

## Features
- User-friendly interface for inputting process details.
- Support for multiple CPU scheduling algorithms.
- Visualization of scheduling results through Gantt charts.
- Calculation of performance metrics such as average waiting time and turnaround time.

## Files
- **cpu_simultion.html**: Contains the HTML structure, CSS styles, and JavaScript functionality for the simulator.

## Usage Instructions
1. Open the `cpu_simultion.html` file in a web browser.
2. Select a scheduling algorithm from the dropdown menu.
3. Input the process details such as arrival time, burst time, and priority (if applicable).
4. Click on "Add Process" to include the process in the simulation.
5. Once all processes are added, click on "Submit" to run the simulation.
6. View the results, including the Gantt chart and performance metrics, displayed on the screen.

## Requirements
- A modern web browser (Chrome, Firefox, Safari, etc.) to run the simulator.
